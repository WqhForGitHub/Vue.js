# Vue 3 Demo 合集

> 200 个 Vue 3 + TypeScript + Vite + Vue Router + Pinia 示例项目

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue 3 | ^3.4.0 | 渐进式 JavaScript 框架（Composition API） |
| TypeScript | ^5.4.0 | 类型安全的 JavaScript 超集 |
| Vite | ^5.2.0 | 下一代前端构建工具 |
| Vue Router | ^4.3.0 | Vue.js 官方路由管理器 |
| Pinia | ^2.1.0 | Vue.js 轻量级状态管理库 |

## 快速开始

每个 demo 文件夹都是独立的项目，进入对应目录后即可运行：

```bash
cd 001-基础入门项目

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构

每个 demo 的目录结构如下：

```
├── index.html                # HTML 入口
├── package.json              # 依赖与脚本
├── vite.config.ts            # Vite 配置
├── tsconfig.json             # TypeScript 配置
├── tsconfig.node.json        # Node 环境 TS 配置
├── .gitignore
├── README.md                 # 项目说明
└── src/
    ├── main.ts               # 应用入口
    ├── App.vue               # 根组件
    ├── style.css             # 全局样式
    ├── env.d.ts              # 类型声明
    ├── router/
    │   └── index.ts          # 路由配置（懒加载）
    ├── stores/
    │   └── counter.ts        # Pinia 状态管理
    ├── views/
    │   ├── HomeView.vue      # 首页
    │   └── AboutView.vue     # 关于页
    └── components/
        └── HelloWorld.vue     # 通用组件
```
